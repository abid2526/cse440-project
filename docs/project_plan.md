# Project Plan

## Project Title

Adventure Quest: A Dynamic Narrative Game Using Factor Graphs

## Introduction

Adventure Quest is a simple adventure game developed as part of the CSE440 Artificial Intelligence course. The main objective of this project is to demonstrate how Factor Graphs can be used for decision-making in a game. Instead of following a fixed storyline, the game changes according to the player's current state and the choices they make throughout the adventure.

The project focuses on applying an AI concept in a practical and interactive way while keeping the game simple enough to complete within the project timeline.

## Problem Statement

Many simple adventure games have fixed storylines where every player experiences the same sequence of events. This makes the gameplay predictable.

Our project aims to solve this by using a Factor Graph to make decisions based on the player's current condition. As a result, different players may experience different events and reach different endings.

## Objectives

- Develop a simple adventure game using Python.
- Implement Factor Graphs for AI-based decision making.
- Create a dynamic story that changes according to player choices.
- Demonstrate the practical application of an AI technique.

## Project Scope

The game will include:

- Three main locations:
  - Village
  - Forest
  - Cave

- Different events in each location.
- A player system with health, gold, weapon, reputation, and location.
- AI-based event selection using a Factor Graph.
- Multiple possible endings based on player decisions.
